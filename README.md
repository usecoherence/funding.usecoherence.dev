# funding.usecoherence.dev

Grant and funding operations site for Coherence. Static website generated by
11ty, backed by a local SQLite grant tracker with a TypeScript CLI.

## Layout

```text
website/  11ty site (pages, styles, data adapter)
grant/    TypeScript app: CLI, modules, Drizzle schema, migrations, tests
deploy/   publish scripts (pgs.sh, Cloudflare DNS, Fastmail)
data/     local SQLite (gitignored)
```

## Commands (run from repo root)

```bash
npm run site:dev       # 11ty dev server
npm run site:build     # build website into website/public
npm run db:generate    # generate Drizzle migration from schema
npm run db:migrate     # apply migrations to data/grants.sqlite
npm run cli -- --help  # grant CLI
npm test               # isolated data tests (temp DBs)
npm run check          # types + lint + format
npm run deploy         # build + rsync website/public to pgs.sh
```

## Deploy

`npm run deploy` publishes `website/public` to the existing pgs.sh project
`funding-usecoherence`. Credentials come from `.env` (`PGS_USER`, etc.).

Live site: https://funding.usecoherence.dev
Detail pages: https://funding.usecoherence.dev/grants/<slug>/

## Notes

- The SQLite database is local-only and never committed (`data/grants.sqlite`).
- Artifacts are published to the site only via an explicit allowlist in
  `grant/exports/website.ts` (empty by default).
